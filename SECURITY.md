# Security

## Report a problem

Use GitHub private vulnerability reporting on this repository.
Do not open a public issue for a security problem.
Include the steps to reproduce it and the version you tested.

## What to expect

The maintainer reads each report and replies in the report thread.
No fixed response time is promised yet.

## Scope

The app runs on your computer and stores learning records on your disk.
Imported lessons can contain checks and tutor instructions written by other people.
Report any case where a lesson reads files outside its folder, runs code without your consent, or widens what your agent can do.

## Your own data

Never post learning records, keys, or `cloud-config.local.json` in an issue or a pull request.
